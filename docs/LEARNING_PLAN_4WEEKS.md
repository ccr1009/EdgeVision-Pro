---

## 一、学习方法:每个知识点都走这 6 步

1. **懂概念(10 分钟)**:这玩意儿解决什么问题?(先问「为什么」,再问「怎么做」)
2. **让最小例子跑起来(5 分钟)**:先看结果,建立正反馈。
3. **逐行搞懂(最关键)**:每行问「删了会怎样?」,不懂立刻问 AI。**看不懂 = 没学到**。
4. **故意改坏它(最值钱)**:改错路径、删掉检查、类型弄错……看**编译报错/运行报错/结果错**长什么样。排错能力就这么练出来。
5. **自己写个变体**:不看原代码,自己写个稍不同的。写不出就回第 3 步。
6. **一句话讲清 + 记笔记**:用大白话解释(费曼法),写进 `/root/lab/README.md`。

> **核心:被动看视频没用,「改坏→排错→重写」才入脑。**

### 用 AI 的正确姿势
- 让 AI **逐行讲解**代码;
- 让 AI **故意给你出 bug**,你来排;
- 你写的代码贴给 AI **挑错**;
- **别让 AI 替你写完整代码**——那样你什么都没学到。

### 判断「学到位」的标准
- 能**不看资料**默写出核心流程;
- 看到报错能**猜出大概原因**;
- 能把例子**改成自己的需求**。

## 三、每周实验表(详情)

### 第 1 周:文件 IO / 系统调用 + 进程
**看视频重点**:文件描述符、`open/read/write/close/lseek`、`ioctl`、`mmap`、`fork/exec/wait`。

| # | 实验 | 学到什么 | 验收标准 |
|---|---|---|---|
| E1 | ✅ 读 `/sys/class/thermal/thermal_zone0/temp` | open/read/close、sysfs | 打印 `38.85 C`,数值会跳变 |
| E2 | ✅ 用 `stat` 和 `open+lseek(SEEK_END)` 读 `.rknn` 大小 | 文件 IO vs 系统调用 | 两法结果一致(6526425 字节) |
| E3 | ✅ `open/write` 控 LED + `ioctl(TIOCGWINSZ)` 读终端尺寸 | 写 sysfs、ioctl 控制 | 物理灯快闪+保持常亮，终端行列打印 |
| E4 | ✅ `fork()` + `execvp("uname",...)` + `waitpid` | 进程生命周期/退出码/防僵尸 | 打印 uname 结果 + 退出码 0 + 实测消灭 `<defunct>` |
| E5 | ✅ 遍历 `/proc/[pid]/comm` | 目录遍历、`dirent` | 成功扫描板上 247 个进程并打印对应名称 |

### 第 2 周:多线程 (★ 针对大厂加料: NPU 3核并行异步调度池)
**看视频重点**:`pthread`、`mutex`、`condition_variable`、原子操作。
- E1: 3 线程各跑一次 rknn 推理 (复用 `deploy/cpp`)
- E2: 生产者-消费者 (采集队列 → 推理队列，条件变量与互斥锁)
- E3: 加锁 vs 无锁，100 万次计数与原子操作 `std::atomic`
- **★ 加料实战 (校招王牌)**: 基于 RK3588 NPU Core 0/1/2 绑定，实现多线程异步任务调度池，突破单核 24 FPS 瓶颈。

### 第 3 周:Socket 网络编程 (★ 针对大厂加料: 边缘智能网关推流)
**看视频重点**:`socket/bind/listen/accept/connect/send/recv`、字节序、阻塞/非阻塞。
- E1: TCP echo server (电脑 `nc` 连)
- E2: TCP client 上报板端状态到电脑
- E3: 4 字节定长头 + 目标检测 BBox 结构体 (处理 TCP 粘包与网络字节序转换)
- E4(选): UDP 广播局域网自动发现
- **★ 加料实战 (校招王牌)**: 把板子打造成工业级边缘网关，推理结果实时通过网络推送上位机。

### 第 4 周:守护进程 + epoll + 信号 (★ 针对大厂加料: 落地三大灵魂考点)
**看视频重点**:`daemon/setsid`、`signal/sigaction`、`select/poll/epoll`。
- E1: server 改守护进程 + systemd 服务
- E2: epoll 多路复用，同时处理网络通信与周期定时器
- E3: SIGTERM 优雅退出与资源释放
- E4: 综合「采集 → 推理 → 上报」全链路服务，开机自启
- **★ 冲刺大厂面试三大杀招**:
  1. **DMA-BUF 零拷贝**: RGA 硬件缩放直通 NPU，消除 CPU 内存拷贝延迟；
  2. **INT8 量化掉点与吞吐分析**: FP16 vs INT8 耗时对比与校准数据集影响；
  3. **高可用性设计**: systemd 守护 + 看门狗 (Watchdog) 超时复位。
