## 核心项目经历（双核驱动）

### 项目一：基于 RK3588 的端侧多目流媒体智能网关与轻量化 BEV 空间感知系统 (EdgeVision Pro)
* **项目周期**：2026.08 – 至今 | **角色**：核心独立架构师与开发者
* **项目描述**：针对工业无人机、车载智驾与智能边缘 IPC 场景，在 10W 功耗的国产边缘异构芯片（RK3588）上，从底层全硬件零拷贝流媒体到上层 3D 鸟瞰空间感知，构建了一套端到端高吞吐、低延迟的嵌入式实时分析系统。
* **核心职责与工程攻关**：
  1. **全链路硬件零拷贝（Zero-Copy DMA-BUF）架构**：针对多路高清流内存搬运瓶颈，设计了基于 Linux `dma_buf` 的共享内存管线（`MPP 硬件解码 -> RGA 硬件颜色缩放 -> RKNN NPU 物理直投`），彻底消除了用户态与内核态之间的 3 次 `memcpy`，单帧节省内存总线带宽 **8.6 MB**，CPU 占用率从 80% 降至 **< 8%**。
  2. **轻量化单目 3D 深度解算与 BEV 空间雷达**：拒绝学术界高功耗重型 Transformer 算子，采用“针孔相机接地点反投影（IPM）+ 类别尺寸先验”工程算法；实现从 2D 检测框到自车坐标系下空间距离 $[X, Y, Z]$ 的微秒级解析，实时生成 8 顶点 3D 立体线框及带有 10m~50m 距离刻度的顶视 **BEV 鸟瞰雷达地图**。
  3. **三核 NPU 动态调度与 INT8 高保真量化**：设计 `rknn_core_mask` 调度器，将多路视频流动态负载均衡至 RK3588 的 3 个独立 NPU 核心（单核 2.0 TOPS，共 6.0 TOPS）；设计代表性校准集进行非对称 INT8 PTQ 量化，实测特征图余弦相似度达到 **0.9965**，模型体积压缩 **33%**。
  4. **工程交付与性能表现**：采用 C++17 进行模块化解耦与 AArch64 交叉编译；纯算法自研实现零依赖 ByteTrack；构建涵盖 7 类场景的自动化回归测试（100% 通过）；在真实道路车流视频上实现 **20.5 FPS** 稳定吞吐，单帧物理 NPU 推理延迟降至 **< 6.0 ms**。

### 项目二：面向自动化装备 CAD 建模的物理约束闭环多智能体系统 (equipdes)
* **项目周期**：2026.08 – 至今 | **角色**：课题主负责人 / 第一作者（论文与专利在审）
* **项目描述**：针对大模型生成 CAD 代码容易出现尺寸链推理崩溃与上下文截断的业界痛点，研发了首个结合结构化中间表示、OpenCASCADE 工业几何内核与国家标准公理闭环验证的自动化装备设计智能体系统。
* **核心职责与工程攻关**：
  1. **声明式四表中间表示（IR）设计**：构建由需求表（RequirementSpec）、方案表、语义装配表（AssemblySpec）与验证报告构成的四表解耦 IR；通过“端口与配合机制（Port & Connector）”剥离大模型对三维连续坐标的幻觉计算，位姿完全由确定性 Placement 求解器解算。
  2. **工业几何内核沙箱化与系统加固**：集成 OpenCASCADE (OCCT) / CadQuery 几何计算内核；针对 C++ 内核在复杂布尔运算中偶发的底层崩溃与内存泄漏，设计了多进程 Worker 沙箱隔离框架与安全自愈机制，实现千次批量合成的长期高可用。
  3. **国家标准驱动的确定性物理验证器**：构建涵盖 20+ 项物理指标的工程公理注册表（含导轨跨距比、螺栓拧入深度、丝杠临界转速等国标 GB/T 检验以及全行程动态干涉扫掠），以确定性数学检验彻底杜绝多模态大模型（VLM）打分的主观性与视觉死角。
  4. **分层自愈搜索策略（VFAS）与学术实证**：提出“闭式物理算子爬山 -> 残差驱动参数反思 -> 动作受限补丁”三级搜索算法；在 42 组留出跨工况装备测试集上实现 **100% (42/42)** 物理全绿通过率，显著性检验达成统计学优势（Wilcoxon 符号秩检验 **$p = 0.0156 < 0.05$**）。
  5. **工业全闭环交付**：实现从自然语言需求一键输出 STEP 工程模型、加工物料清单（BOM）、选型计算书以及基于 Three.js 的轻量化 WebGL 3D 离线装配动画交互器。
