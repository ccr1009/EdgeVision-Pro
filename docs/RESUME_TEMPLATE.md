## 核心项目经历（双核驱动）

### 项目一：RK3588 端侧推理加速与端侧具身智能体（EdgeVision）
* **项目周期**：2026.08 – 至今 | **角色**：独立开发
* **项目描述**：在 RK3588（6 TOPS / 三核 NPU）开发板上，从模型图改造、量化精度控制到端侧大模型 Tool Calling，构建了一套可复现、数字全部来自真机实测的端侧 AI 部署与具身智能体系统。
* **核心职责与工程攻关**：
  1. **DFL-Free 模型图手术（性能优化主线）**：定位出 YOLOv8 检测头中 Transpose/Softmax/Reshape 三个 CPU 回退算子吃掉 **49% 帧时间（18.44 ms）**，用 ONNX 图手术把 DFL 解码链从计算图搬到 CPU 侧自研解码器；数值等价验证 `box max|Δ|=1.22e-4 px`、`cls max|Δ|=0`（float32 精度极限）。**纯推理 37.19 → 15.95 ms（−57%），模型 INT8 体积 6.22 → 4.34 MB（−30.2%，FP32 原图 12.2 MB），单帧全链路 37.19 → 20.58 ms（26.9 → 48.6 FPS）**。
  2. **INT8 量化掉点控制（用真 mAP 而非余弦相似度）**：对照实验定位出**合成校准集导致 cls 分支塌缩成常数 `sigmoid(0)=0.5`**（框对但分类头彻底失效）；重建真实场景校准集后，在 COCO128（128 图 / 929 GT / 71 类）上实测 **mAP@0.5 FP32 0.6087 → INT8 0.6002，绝对掉点 0.85 个点（−1.4%）**，用 1.4% 精度换 45% 延迟下降。
  3. **三核 NPU 真并行与编译优化**：`rknn_set_core_mask` 硬绑定 3 个独立 context，实测 **59.3 FPS / 2.21×**（并如实指出三核各仅 49% 负载、非线性加速的原因）；排查出**构建系统 `CMAKE_BUILD_TYPE` 为空、全程无 `-O` 标志**这一持续 20 余天的隐性坑，修复后 `taskset` 绑核 A/B 实测 **CSC 52.02 → 33.58 ms（1.549×）、全链路 76.93 → 55.84 ms（−27.4%）**，并用两个"不该变"的对照组排除测量漂移。
  4. **MPP 硬件编解码与负结论**：实现 MPP 硬件 JPEG 解码（**p50 1.03 ms vs 软解 7.76 ms，7.6×**，9 图 PSNR 49.9~77.2 dB）；对称实现硬件 JPEG 编码并验证正确（Y-PSNR 42.46 dB），但实测**比软编慢 1.07~1.88×**，通过中断计数证明确实走了硬件，用延迟模型给出根因（0.35 ms 固定 ioctl/中断往返 + 每像素算力打平），**主动把该项从优化路线图划掉**。
  5. **端侧大模型具身智能体**：RKLLM + Qwen3.5-2B W8A8 纯单板离线，实现硬件 Tool Calling 闭环（温区/NPU/内存、视觉帧、LED 控制、巡检事件 5 类工具）；一条自然语言跑完「巡检 → 研判 → 执行 → 汇报」，实测端到端 106.5~112.2 s、连续 4~5 个工具、Observation 20~29 条全合法 JSON。
  6. **快慢双系统与可靠性工程**：巡检守护快层 5 s 周期状态机 + 迟滞（快层刻意不加载 LLM，避免 NPU 竞争与长尾时延），事件落盘供慢层 LLM 消费；建立 **12 用例 Agent 回归测试**（含故障注入 + `finally` 自动恢复）全绿。**最有价值的一次 debug**：演示判 PASS 但翻 trace 发现 Agent 汇报"LED 熄灭导致过热保护被抑制"而灯正在爆闪 —— 定位为**周期性物理量单点采样混叠**而非模型幻觉，重构成"进程存活判定 + 多点采样"；另补 sys_prompt 领域常识修复"49°C 被判为永久损坏风险"的误判。

### 项目二：面向自动化装备 CAD 建模的物理约束闭环多智能体系统 (equipdes)
* **项目周期**：2026.08 – 至今 | **角色**：课题主负责人 / 第一作者（论文与专利在审）
* **项目描述**：针对大模型生成 CAD 代码容易出现尺寸链推理崩溃与上下文截断的业界痛点，研发了首个结合结构化中间表示、OpenCASCADE 工业几何内核与国家标准公理闭环验证的自动化装备设计智能体系统。
* **核心职责与工程攻关**：
  1. **声明式四表中间表示（IR）设计**：构建由需求表（RequirementSpec）、方案表、语义装配表（AssemblySpec）与验证报告构成的四表解耦 IR；通过“端口与配合机制（Port & Connector）”剥离大模型对三维连续坐标的幻觉计算，位姿完全由确定性 Placement 求解器解算。
  2. **工业几何内核沙箱化与系统加固**：集成 OpenCASCADE (OCCT) / CadQuery 几何计算内核；针对 C++ 内核在复杂布尔运算中偶发的底层崩溃与内存泄漏，设计了多进程 Worker 沙箱隔离框架与安全自愈机制，实现千次批量合成的长期高可用。
  3. **国家标准驱动的确定性物理验证器**：构建涵盖 20+ 项物理指标的工程公理注册表（含导轨跨距比、螺栓拧入深度、丝杠临界转速等国标 GB/T 检验以及全行程动态干涉扫掠），以确定性数学检验彻底杜绝多模态大模型（VLM）打分的主观性与视觉死角。
  4. **分层自愈搜索策略（VFAS）与学术实证**：提出“闭式物理算子爬山 -> 残差驱动参数反思 -> 动作受限补丁”三级搜索算法；在 42 组留出跨工况装备测试集上实现 **100% (42/42)** 物理全绿通过率，显著性检验达成统计学优势（Wilcoxon 符号秩检验 **$p = 0.0156 < 0.05$**）。
  5. **工业全闭环交付**：实现从自然语言需求一键输出 STEP 工程模型、加工物料清单（BOM）、选型计算书以及基于 Three.js 的轻量化 WebGL 3D 离线装配动画交互器。
