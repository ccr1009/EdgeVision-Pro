# 写作规范（所有撰写者必须遵守）

你要写的是**一本"面试问答详解手册"里的某一章**，读者是作者本人（研一学生，RK3588 项目作者），
他的目的是：**面试前背下来、并且真的理解**。

最终产物会被脚本自动转成 Word 文档，所以**必须严格使用下面的 Markdown 子集**，多一个语法都会渲染失败。

---

## 一、允许的语法（只有这些）

| 语法 | 含义 | 说明 |
|---|---|---|
| `# 第 X 章 标题` | 章标题 | **每章文件只有 1 个**，且必须是第一行 |
| `## 一、小节标题` | 一级小节 | 用「一、二、三」编号 |
| `### Q：问题` | 一个问答题目 | 主结构，见下方模板 |
| `### R：追问：xxx` | 追问子块 | 可选 |
| 普通段落 | 正文 | 一段一行，**不要硬换行**（不要在句子中间敲回车） |
| `- 列表项` | 无序列表 | 只支持一层，不要嵌套 |
| `1. 列表项` | 有序列表 | 只支持一层 |
| `> 引用` | **提示框 / 费曼讲解** | 每行都以 `> ` 开头，连续多行算一个框 |
| `**粗体**` | 强调 | 行内 |
| `` `代码` `` | 行内代码 | 行内 |
| ```` ```代码块``` ```` | 多行代码 / 图 | 前后各一行 ```，语言标记可省略 |
| 表格 | `\|表头\|表头\|` + `\|---\|---\|` + 数据行 | 标准 Markdown 表格 |

**禁止**：`####` 四级标题、`---` 分隔线、图片 `![]()`、链接 `[]()`、嵌套列表、HTML、表情符号（emoji）。

## 三、单个 Q 的写法（最重要）

```markdown
### Q：`read` 返回 0 是什么意思？

**一句话答案：** 是 EOF，对端关闭或文件读完，不是错误。

**展开讲：** `read` 的返回值有三种情况，必须分开处理：正数=真读到的字节数
（**不保证读满**，要循环）；0=EOF（对端关了/文件到底了）；-1=真出错，看 `errno`。
我踩过的坑是读完 EOF 还在用 buffer，结果把上一帧的垃圾数据当成新的读了进去。

**如果被追问「那 EINTR 呢？」：** 被信号打断，不是失败，`while (n < 0 && errno == EINTR)` 重试即可。

> 【费曼讲解】把 `read` 想成"用勺子从锅里舀汤"：你要求舀 8 勺，锅里有 5 勺，那这次就只给你 5 勺
> ——它没骗你，是你自己假设了"要多少给多少"。舀到锅空了（返回 0）也不叫失败，叫"汤没了"。
> 只有"勺子掉了"（返回 -1）才是真失败。
```

要点：
- `**一句话答案：**` 必须紧跟在 `### Q：` 后面，**先给结论**（面试口述时先甩结论再展开）。
- `**展开讲：**` 是主体，写**原理 + 自己的实测数据/代码细节**，别写成教科书。
- `**如果被追问「xxx」：**` 可以有多条，也可以没有。追问是面试官真正的杀招，尽量写满。
- `> 【费曼讲解】` **只给"真的难懂"的概念用**：每章 2~5 处，不要每问都写。判断标准是
  「一个没学过这个的人第一次听会卡住的地方」，比如：为什么条件变量必须配 mutex、DFL 是什么、
  为什么三核不是 3 倍、什么是背压、量化 scale 为什么这么要命、什么是粘包。
  **费曼四步**：① 用生活类比讲一遍 ② 指出"不懂的人通常会怎么错想" ③ 用一句话戳破
  ④ 再回到技术术语。禁止只写"简单来说就是……"这种假费曼。

## 四、内容红线（违反 = 返工）

1. **数字必须真实**。任何数字都要能在源文件（`docs/interview/W*.md`、`docs/BENCHMARKS.md`、
   `docs/TROUBLESHOOTING.md`、`docs/tech_notes/*`）里找到出处，**禁止自己算一个新数、禁止四舍五入编造**。
   拿不准就不写数字，写"实测有明显提升"。
2. **不许把"没做的事"写成"做了"**。`docs/interview/README.md` 有一张「诚实边界」表，
   RGA 硬件 CSC / DMA-BUF 零拷贝 / RTSP-WebRTC / H.264-H.265 硬解 / ByteTrack 进 C++ / 整机功耗 / ASR
   全部是**未实现**。提到时必须写成"没做，但我评估过/我判断不划算"，不能写成已落地。
3. **全中文**。技术名词保留英文原样（`epoll`、`futex`、`DFL`、`RKNN`）。
4. 语气：**像私教在旁边跟你说话**，不要书面公文体。允许"你会发现""这里有个坑"。
5. 不要重复堆砌同一句话；同一条原理在本章内讲一次就够。

## 五、长度

- 普通章（第 5~8 章）：2500~5000 汉字。
- 重点章（第 9~13 章 端侧推理、第 14~16 章 Agent）：4000~7000 汉字，宁可细不要短。
- 判断标准：**读者遮住答案，能不能靠这一章自己把问题答回来。**

---

## 六、输出

写到指定的 `.md` 文件，UTF-8 编码，文件第一行就是 `# 第 X 章 ...`。
写完后自己回头检查一遍：有没有用到被禁止的语法、有没有编造的数字。
