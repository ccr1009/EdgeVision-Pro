# 第 0 章 这本书怎么用

> 一句话心智模型：这不是一份"押题清单"，而是一台**面试模拟器**——每一问都按"先甩结论、再讲原理、再讲我踩的坑、再预演追杀"四层来写，读到哪一层停在哪一层。

## 一、先建立心智模型

```
    面试现场                    本书的对应结构
    ────────                    ────────────
    面试官抛问题      ─────►     Q：问题
    你先答一句        ─────►     一句话答案        ← 先练这一层，30 秒内说完
    他让你展开        ─────►     展开讲            ← 讲原理 + 我项目里的真实细节
    他挑刺            ─────►     如果被追问「…」    ← 这一层决定你是 60 分还是 85 分
    你答不上来        ─────►     第 15 章的接话话术
```

**记住这一个比喻**：面试不是考试，是**两个工程师在同一个问题上对齐认知**。面试官不指望你背完全部，
他在验证三件事：**你有没有真的动手**、**你知不知道自己方案的边界**、**你出问题时能不能自己修**。
本书所有内容都服务于这三件事。

## 三、三分钟自我介绍模板

**一句话答案：** 我是 XX，研一，方向是端侧 AI 部署。我这大半年在一块 RK3588 板子上，从零把一条"摄像头 → NPU 推理 → 大模型 Agent"的完整链路做通了，全部是板端实测数据。

**展开讲：**（按"一句项目 + 三个数字 + 一句边界"的结构说）

```text
我是 XXX，目前在 XX 大学读研一，方向是端侧 AI 部署 / 边缘计算。

这半年我在 EVM3588-B（RK3588）上做一个端侧视觉巡检系统，
链路是"摄像头 MJPEG → MPP 硬件解码 → NPU 三核并行推理 → TCP 推流 → 端侧大模型 Agent 调度"。

几个实测数字：
  · 纯推理 15.95 ms/帧，比 DFL 图手术之前的 37.19 ms 降了 57%；
  · 单帧全链路 20.58 ms，约 48.6 FPS；三个 NPU 核聚合 59.3 FPS；
  · INT8 量化在 COCO128 上 mAP 只掉 1.4%（0.6087 → 0.6002）。

在上面又做了一层具身 Agent：RKLLM 跑 Qwen3.5-2B，ReAct 多步调用 5 个硬件工具，
两幕演示端到端 106~112 秒、Observation 全部是合法 JSON。
另外还有一个独立的 C++ 巡检守护做快慢双系统，12 条回归用例全绿。

边界我也清楚：RGA 硬件 CSC、DMA-BUF 零拷贝、RTSP 这部分我评估过但没做，
因为它们不是当时的瓶颈，我优先去改了模型导出和编译选项。
```

**如果被追问「你负责哪部分？」：** 全部是我自己做的，从板子到应用层。硬件是买的现成开发板，
算法我用的是 YOLOv8 官方模型自己改的导出，不是我训的。

## 四、三个月复习节奏

| 时间 | 做什么 | 验收标准 |
|---|---|---|
| 第 1~2 周 | 通读第 1、6、7、8 章，把项目重新走一遍 | 能脱稿讲 3 分钟 |
| 第 3~4 周 | 第 2~5 章 + 第 9 章 | 每章合上书能自己画图 |
| 第 5~6 周 | 第 10~13 章 | 能画出 Agent 状态机和守护系统结构 |
| 第 7~8 周 | 第 14 章 + 反复过附录 | 20 个追杀问题能扛住 |
| 投递期 | 每天 30 分钟只看"一句话答案" | 手机响一个弹窗 |

**简历怎么和这本书配合用**：投出去的简历有两份，一份偏嵌入式 Linux 应用研发，一份偏端侧 AI 部署，同一套项目但重心完全不同。第 16 章和第 17 章是专门为此写的——把简历上每一条表述映射到书里的章节，并给出"面试官指着这一行问你张嘴就说什么"的三十秒版本；附录第六节是速查矩阵，第七节是十二句不能说错的口径。

用法很简单：**改简历之前先看这两章**，简历上写的每一条，书里都要有对应的证据；书里没有的要么补上，要么从简历上删掉。

## 五、这一章的"记忆锚点"

- 面试官验证的是三件事：**你动过手 / 你知道边界 / 你能自愈**。
- 每个回答的结构永远是：**一句话结论 → 原理 → 我的实测 → 边界**。
- 数字讲**来源**：板端实测、什么模型、什么条件；不讲"大概、差不多、很快"。

## 六、开始之前的一句提醒

> 这本书里每一个数字，你都要能说出"怎么测的"。说不出来的数字就不要背——
> 面试官只要往下追一层"这个数怎么来的"，背数字的人就塌了，而做过的人会开始画图。
