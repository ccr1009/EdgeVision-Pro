> **发明名称**：一种基于四表中间表示与确定性物理验证的装备装配体自主设计系统及方法  
> **建议申请人**：南方科技大学  
> **建议第一发明人**：[你的姓名]  
> **技术领域**：人工智能、计算机辅助设计（CAD）、自动化装备制造、复杂智能体系统（Multi-Agent System）

---

## 一、 背景技术与现有技术的缺陷

随着大语言模型（LLM）的发展，利用自然语言直接生成机械 CAD 模型已成为研究热点。然而，直接依靠大模型端到端直出（End-to-End）多零件装配体存在三大不可逾越的技术缺陷：
1. **尺寸链推理幻觉**：机械装备（如直线模组、龙门平台）内部尺寸高度耦合。当工况行程发生变化时，导轨长度、丝杠轴长与基座开槽必须同步联动，大模型单阶段直出经常改动一处而忽略连锁尺寸传递，导致严重的内部过盈干涉或间隙失配；
2. **上下文容量截断**：整机 10~25 件装配体的 CAD 几何代码往往超过 12,000 tokens，直接单次输出极易发生语法截断崩溃；
3. **传统检验手段主观且不可靠**：现有方案（如利用多模态大模型 VLM 看图打分）存在致命的视觉死角，无法检测零件内部装配面、螺栓预留深度等毫米级隐蔽干涉，且评委一致性低，无法达到工业量产要求。

---

## 二、 发明技术方案概述

本发明提出了一种将大模型语义离散探索与确定性物理约束计算深度解耦的自主闭环设计系统：

```
自然语言需求 -> [需求结构化] -> 四表中间表示 (IR) -> [确定性 Placement 求解器] 
    -> [OpenCASCADE 几何沙箱] -> [国标 GB/T 公理确定性检验] 
    -> [三级分层自愈搜索 VFAS] -> 输出合格 STEP 工程文件与 BOM
```

### 核心技术特征：
1. **四表解耦中间表示（4-Table IR）**：
   - 划分 `RequirementSpec`（需求表）、`DesignScheme`（方案拓扑表）、`AssemblySpec`（装配语义表）与 `ValidationReport`（物理与公理检验报告）；
   - 大模型仅负责声明装配接口端口（Port）与贴合关系（Connector），**所有零件的空间绝对坐标 $(x, y, z, 	ext{roll}, 	ext{pitch}, 	ext{yaw})$ 严格由确定性位姿求解器通过正向运动链计算求出**。
2. **OpenCASCADE 工业几何内核子进程沙箱隔离**：
   - 将底层 C++ 几何计算与主控 Agent 进程解耦，利用 IPC 管道与安全退出信号捕获，彻底杜绝复杂拓扑布尔求交时的内存段错误（SIGSEGV）污染主系统。
3. **基于国家标准（GB/T）的确定性物理验证器**：
   - 固化涵盖 20+ 项物理指标的公理规则库（导轨跨距比、螺栓拧入深度、丝杠临界转速/DN值等），并结合几何内核执行全行程动态扫掠求交，不依赖任何主观模型评判。
4. **分层自愈搜索策略（VFAS）**：
   - 建立“Level 1 闭式物理算子爬山 $	o$ Level 2 诊断残差驱动的参数重估 $	o$ Level 3 自由几何补丁”的三级递进修复环，显著收敛可行解空间。

## 三、 权利要求书核心要点（独立权利要求与从属项）

### 独立权利要求 1（方法权利要求）：
一种基于四表中间表示与确定性物理验证的装备装配体自主设计方法，其特征在于，包括以下步骤：
1. 接收非结构化工程需求文本，解析生成结构化需求参数表；
2. 基于领域技能库检索匹配初始设计方案，生成解耦的三维装配语义中间表示，其中所述中间表示仅包含零件装配基准面与配合类型约束；
3. 调用确定性约束求解器，根据所述配合类型约束求解每个零件的绝对空间位姿矩阵；
4. 启动子进程沙箱，调用三维几何造型内核（OpenCASCADE）生成装配体实体模型；
5. 调用包含国家标准的确定性工程公理库与动态干涉扫掠算法，输出数值化检验报告；
6. 当检验未全部通过时，依据残差类型触发分层自愈搜索机制，依次执行闭式物理算子爬山与局部参数重估，直至所有物理指标全绿通过；
7. 输出标准 STEP 工程模型文件与加工物料清单。

### 从属权利要求关键点：
- 权利要求 2：所述四表中间表示的字段解耦结构；
- 权利要求 3：所述确定性位姿求解器基于正向运动学树的传递计算方式；
- 权利要求 4：所述子进程沙箱的多进程 Worker 池管理与内存异常安全退出机制；
- 权利要求 5：所述三级自愈搜索（确定性闭式算子、局部参数反思、自由补丁）的递进状态转移条件。

## 四、 具体实施例与实证数据（证明创造性与实用性）

在 42 组涵盖轻载、重载、立式、高速工况的工业留出测试集上进行了全量验证：
- **可行解收敛率**：在不引入人工干预的情况下，本发明自愈搜索机制将装配体确定性检验通过率提升至 **100% (42/42)**；
- **统计学显著性**：相对于单阶段直出与朴素消融基线，经 Wilcoxon 符号秩检验，收敛优势具有统计学显著性（**$p = 0.0156 < 0.05$**）；
- **工业产物**：单次合成耗时均值 $< 38$ 秒，一键交付符合 ISO 10303 标准的 STEP 装配模型，并在任意工业 CAD 软件（如 SolidWorks、CATIA、中望CAD）中实现零干涉无缝读取。
