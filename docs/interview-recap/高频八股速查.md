# 高频八股速查（面试前 10 分钟）

> 一句话一答。答不出来的，回对应周的文件补。
> 【W1】文件IO/进程 【W2】多线程 【W3】网络 【W4】服务化

---

## 系统与进程【W1】

**1. fd 是什么？**
进程内的一张表的下标；0/1/2 是 stdin/stdout/stderr，新开的从 3 起。

**2. `read` 返回 0 是什么意思？**
EOF / 对端关闭。**不是错误**，`-1` 才是错误。

**3. `read` 返回 -1 且 errno=EINTR？**
被信号打断，**重试**，不是失败。

**4. `stat` 和 `lseek` 测大小的区别？**
`stat` 查元数据不打开文件；`lseek` 要在 fd 上，会移动读写位置。

**5. `ioctl` 干什么用的？**
设备专属控制通道，传「命令 + 参数」，不是数据流。

**6. `fork` 为什么快？**
写时复制（COW），只复制页表，谁写谁才真正复制内存。

**7. `exec` 会创建新进程吗？**
不会，替换当前进程的代码段，**PID 不变**。

**8. 僵尸进程怎么来的？**
子进程死了、父进程没 `wait`，退出码没被回收，留下 `<defunct>`。

**9. 孤儿进程有害吗？**
无害，被 PID 1 收养。**僵尸有害**（占进程表项）。

**10. `/proc` 是什么？**
内核实时生成的虚拟文件系统，`ls /proc` 就是看进程表。

## 多线程【W2】

**11. 线程和进程的核心区别？**
线程共享地址空间（通信便宜、易出竞态）；进程独立（隔离好、切换贵）。

**12. `counter++` 为什么不是原子的？**
编译成「读→改→写」三条指令，中间可能被切走。

**13. 实测过丢数据吗？**
2 线程各 100 万次，期望 200 万，**实测 1000093**，丢了 9907。

**14. 锁的底层是什么？**
futex：无竞争时用户态原子指令，有竞争才陷入内核挂起。

**15. 死锁的四个条件？**
互斥、持有并等待、不可剥夺、循环等待。破坏任一即可（常用固定加锁顺序）。

**16. `pthread_create` 传参最容易错什么？**
传 `&i`（循环变量地址），所有线程拿到同一个终值。

**17. `join` 和 `detach`？**
`join` 等它并回收资源；`detach` 让它自生自灭，不能再 `join`。

**18. `atomic` 什么时候不够用？**
要保证**多个变量的一致性**时，必须用 mutex。单变量简单操作才用 atomic。

**19. 条件变量为什么必须配 mutex？**
「判断条件」和「睡眠」必须原子，否则中间会丢信号。

**20. 为什么 `while` 不用 `if`？**
醒来不等于条件成立（虚假唤醒/被抢），`if` 会带着空数据往下跑。

**21. 3 核 NPU 怎么真正并行？**
**3 个独立 context 各绑一核**。单 context 调 `CORE_0_1_2` 只快 3.3%。

**22. 为什么不是 3 倍加速？**
三核各只有 49% 负载，瓶颈在 CPU 侧解码（DFL 头回退占 49% 时间）。

## 网络【W3】

**23. TCP 为什么需要自己定义消息边界？**
TCP 是字节流，没有边界概念，会粘包/半包。

**24. 怎么解决粘包？**
定长包头 + 长度字段，然后**循环收到够为止**。

**25. 为什么结构体要 `#pragma pack(1)`？**
默认内存对齐会塞填充字节，两端大小可能不同，序列化错位。

**26. 为什么要 `htonl/htons`？**
网络字节序是大端，主机多为小端，整数必须转换。

**27. `accept` 返回的是什么？**
**新的连接 fd**；原来的 listen fd 继续接客（迎宾员 + 服务员）。

**28. 非阻塞 `accept` 返回什么？**
`-1` + `errno=EAGAIN`，表示「现在没有」，不是错误。

**29. select / poll / epoll 区别？**
select 有 1024 上限且每次全量拷贝；poll 去了上限但仍全量拷贝；epoll 内核维护红黑树+就绪链表，O(1)。

**30. epoll 的 LT 和 ET？**
LT 没读完继续通知（安全）；ET 只通知一次，必须读到 `EAGAIN`（高效但易错）。

**31. `send` 不检查返回值会怎样？**
对端断开后继续写 → `SIGPIPE` **直接杀掉进程**。要加 `MSG_NOSIGNAL`。

**32. 为什么推流要单独一个线程？**
**背压**：网络卡顿时不阻塞推理线程，NPU 不会空转。

**33. 队列为什么要设上限？**
无界队列在「生产快、消费慢」时会**内存爆掉**。实时系统丢最旧的帧。

**34. TCP 和 UDP 怎么选？**
要可靠有序用 TCP；要低延迟、可容忍丢包用 UDP（摇杆控制 vs 固件升级）。

## 服务化【W4 · 未实操】

**35. daemon 三步？**
`fork` 后父退出 → `setsid` 脱离终端 → 重定向 0/1/2 到 `/dev/null`。

**36. SIGTERM 和 SIGKILL？**
TERM 可捕获、能做优雅退出；KILL(9) 不可捕获、直接杀死。

**37. 信号处理函数里不能做什么？**
不能 `printf`、`malloc`、加锁（非异步信号安全）。要写 pipe 让主循环处理（self-pipe）。

**38. `systemctl enable` 和 `start`？**
`enable` 建开机自启链接（重启生效）；`start` 现在就启动。

**39. `Restart=always` 和 `on-failure`？**
always 怎么退都重拉；on-failure 只有异常退出才重拉。

**40. 硬件看门狗怎么用？**
开 `/dev/watchdog`，定期 `write` 喂狗，超时就**硬件复位整板**。
