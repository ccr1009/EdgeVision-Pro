# BENCHMARKS — stereo3d-rk3588 板端实测

> 全部数字来自 EVM3588-B 真机实测（Debian 11 / OpenCV 4.5.1 / g++ 10.2.1）。
> **测量口径**：真实双摄 `/dev/video81` + `/dev/video83`，1280×720 MJPG 采集，处理尺度 640×360，
> SGBM `num_disp=64, block=5, MODE_SGBM_3WAY`，OpenCV 带 TBB 并行（探针 parallel_for_ 实测 4.10× 加速，
> 46ms 已是并行态真实成本，见第 5 节）。
> 未标定模式（理想平行双目假设 fx=1108.5@1280 / B=60mm 假设值）。
> 测法：demo 内置分段计时（每段 clock 起止），200+ 帧稳态读数。

## 1. 全链路分段耗时（2026-10-24 实测）

| 阶段 | 耗时 | 占比 | 说明 |
|---|---:|---:|---|
| cap（双摄抓取） | 16.3 ms | ~17% | 两颗先 grab 再 retrieve，压同时差 |
| rect（立体矫正 remap） | 5.4 ms | ~6% | CV_16SC2+16UC1 定点映射表，1280×720 灰度 remap |
| **sgbm（视差）** | **46.1 ms** | **~48%** | **最大瓶颈**，640×360 / nd=64 / 3WAY |
| depth（视差→深度） | 0.6 ms | <1% | 纯查表除法 |
| face（Haar 检测+3D） | 20.6 ms | ~21% | 640×360 上 Haar，含直方图均衡 |
| draw + enc（画图+JPEG） | ~12.5 ms | ~13% | 2×2 拼图 1280×720 + JPEG q80 |
| **全链路** | **~102 ms ≈ 9.7~11 FPS** | | 222 帧平均 9.68 FPS |

## 5. SGBM 参数消融（task-5，2026-10-24 实测，每组 200 帧稳态）

> **口径**：独立工具 `ablation_sgbm`（与 demo 同一条 StereoPipeline 代码路径），640×360 未标定模式，
> 逐组重启进程避免状态污染；FPS = 采集+矫正+SGBM+深度（不含 HTTP 推流/人脸检测）。
> 环境变量 `STEREO_NUM_DISP` / `STEREO_BLOCK` 覆盖参数（`stereo_pipeline.cpp` computeDisparity 内
> getenv 入口，缺省用 cfg_ 原值，生产零影响）。

| num_disp | block | sgbm_ms | FPS | 有效视差占比 |
|---:|---:|---:|---:|---:|
| 64（原基线） | 5 | 42.83 | 13.25 | 0.1777 |
| 48 | 5 | 39.88 | 14.74 | 0.1796 |
| **32（推荐）** | **5** | **36.17** | **14.95** | **0.2113** |
| 64 | 7 | 41.71 | 13.99 | 0.1569 |
| 48 | 7 | 39.33 | 14.66 | 0.1801 |
| 32 | 7 | 36.76 | 14.94 | 0.2130 |

**结论（面试可讲）**：
1. **理论 vs 实测的偏差才是真发现**：SGBM 复杂度 O(W·H·N·D)，nd 64→32 理论应省一半，实测只快
   **15.6%**（42.83→36.17ms）——动态规划聚合的访存成本与 D 无关，参数不是万能钥匙。
2. **nd=32 有效视差占比反而最高**（0.211 vs 0.178）：搜索范围小 → 更多像素通过左右一致性与
   唯一性检查；代价是最近可测距离 Z_min=fx_proc·B/nd 从 ~0.52m 退到 ~1.04m（近场人脸定位会丢）。
3. **block 5→7 无收益**：valid_ratio 持平、速度略慢——SAD 单块成本 25→49 像素的理论上涨被
   3WAY 访存主导稀释。
4. **≤20ms 目标参数层面做不到**：降分辨率 480×270 附加实测——(64,5) sgbm 29.0ms、(32,7) 24.3ms，
   但 rect 反升到 ~9ms（map 覆盖范围未变），且 Haar 人脸检测在 270p 明显变弱、牺牲视差分辨率；
   **留作后备手段，暂不启用**（若未来要 ≤20ms 硬指标再开，人脸检测需换更高分辨率图或换模型）。

## 6. 局限（引用时必须一起说）

1. **未标定**：绝对距离不可信（fx 是理想假设值），上表全链路数据只验证「流水线通、量可复现」。
2. **valid_ratio 只是粗验代理**：场景相关非绝对质量指标，nd=32 占比高只说明弃判像素少，
   不代表视差更准；正式精度对比要等标定完成后用已知距离误差做。
3. **faces=0**：真机运行时镜头前无人，人脸链路精度来自合成真值场景（3 节），尚缺真人实测。
4. COCO/YOLO 系指标不适用于本项目；本项目无学习模型（Haar 是级联特征，非训练自建）。
5. 消融快照：板上 `/root/stereo3d/ablation_snaps/`（6 张伪彩视差图），结果 `/root/stereo3d/ablation_results.txt`。
